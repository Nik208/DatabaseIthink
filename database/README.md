# Library — модульное CLI-приложение на Dart

Консольное приложение для учета клиентов, книг, авторов, информации об одолженных книг, ролей пользователей с хранением данных в SQLite.

## Предметная область

Система автоматизации салона:

- роли (`role`);
- Author (`author`)
- пользователи (`user`) с привязкой к ролям;
- Книги (`book`) с привязкой к авторам;
- Информация об одолженных книгах (`borrowdata`) с привязкой к книгам и пользователям;

## Архитектура и структура папок

Проект разделен на модули по слоям:

```text
lib/
  database.dart               # публичный экспорт
  src/
    domain/                # сущности и базовые интерфейсы
      models/
        author.dart
        book.dart
        borrowdata.dart
        identity.dart       # Абстрактный класс Id
        role.dart
        user.dart
      validators/
        validators.dart     # Валидация 
    data/                  # SQLite и SQL-логика
      salon_database.dart
      repositories/
        author_repository.dart
        book_repository.dart
        borrow_repository.dart
        role_repository.dart
        user_repository.dart
    cli/                   # меню и обработка ввода
      menu.dart
      input_helper.dart
bin/
  main.dart                 # точка входа (main)
test/
  database_test.dart            # базовые тесты
```

### Что вынесено в каждый слой и почему

- `domain`: описывает данные и преобразования (`toMap`/`fromMap`), не зависит от SQL и консоли.
- `data`: отвечает за хранение, создание таблиц и CRUD-запросы.
- `cli`: отвечает за взаимодействие с пользователем (`stdin`/`stdout`) и навигацию по меню.
- `bin`: только запуск приложения и закрытие ресурсов.

Такое разделение упрощает поддержку, тестирование и замену инфраструктуры (например, SQLite на другой способ хранения).

## Реализованная функциональность

- просмотр списка клиентов, книг, авторов, информации об одолженных книг и ролей пользователей;
- добавление и удаление клиентов;
- добавление и удаление книг;
- добавление и удаление авторов;
- добавление и удаление информации об одолженных книг;
- добавление и удаление ролей пользователей;
- вывод всех таблиц БД в консоль.

## Валидация

Реализованы проверки:

- обязательный текстовый ввод: значение не пустое после `trim()`;
- числовые поля для услуги: цена и длительность должны быть корректными числами больше 0;
- Возможность добавления и вывода данных в БД

## Тесты

В проекте есть 3 обязательных типа тестов:

1. `toMap/fromMap` для сущности `User`;
2. вставка и чтение клиента из временной SQLite;
3. валидный и невалидный ввода чисел на более чем ноль и на целость

## Запуск

Установить зависимости:

```bash
dart pub get
```

Запустить приложение:

```bash
dart run
```

Запустить тесты:

```bash
dart test
```
